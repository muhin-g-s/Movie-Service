# cold-start

> **Отвечает за:** порядок проверки, находит ли новый агент факты проекта только по репозиторию.
> **Не содержит:** самих фактов, список вопросов и ожидаемых владельцев лежит в [questions.md](questions.md).
> **Читать когда:** пользователь вызвал `/cold-start`, после крупных правок документации или перед пилотной фичей.
> **Проверено при версии конституции:** 3.0.0

## Шаги

1. Прочитай [questions.md](questions.md).
2. Запусти одного агента в свежем контексте через инструмент Agent, тип Explore. В запросе передай вопросы и условия: отвечать только по файлам репозитория, считать, что `CLAUDE.md` не существует, начинать с `AGENTS.md` и идти по ссылкам, на каждый вопрос дать ответ одной фразой и путь файла-источника, при отсутствии ответа написать "нет ответа". Ожидаемые владельцы агенту не показывай.
3. Сверь ответы с владельцами: прочитай файл-владелец каждого вопроса. Вопрос пройден, если агент назвал именно этот файл и ответ ему не противоречит.
4. Для каждого непройденного вопроса определи причину: факта нет в репозитории, то есть утечка, или агент не нашел его по навигации.
5. Измерь размер входного контекста: `wc -lc AGENTS.md CLAUDE.md`. Оценка токенов около одной трети числа символов.
6. Покажи таблицу результатов, причины провалов и размер контекста.

## Границы

- Файлы не правь, правки предложи и передай в `/capture`.
- Если добавляете факт, который агент должен находить, добавьте вопрос и владельца в [questions.md](questions.md) в той же задаче.
