# docs-sync

> **Отвечает за:** порядок синхронизации документации с изменениями: сверка фактов с владельцами и запуск проверки.
> **Не содержит:** самих правил документации ([принцип IX конституции](../../../.specify/memory/constitution.md)) и карты владельцев ([docs/README.md](../../../docs/README.md#карта-источников-истины)).
> **Читать когда:** срабатывает хук Spec Kit или нужно сверить документацию после изменений.

Правила проекта заданы принципом IX конституции. Карта владельцев: `docs/README.md`.

## Шаги

1. Определи изменения: `git status --short` и `git diff`. Для фичи учти также `specs/<NNN-feature>/`.
2. Для каждого изменившегося факта найди владельца в карте источников истины и обнови его. Остальные места должны только ссылаться, копий быть не должно.
3. Если изменилась конституция, проверь, что версия повышена, а `AGENTS.md`, `code-review.md` и `docs/` не противоречат новой редакции.
4. Если решена тема из реестра отложенных решений, удали строку из [реестра](../../../docs/decisions/README.md#отложенные-решения) и запиши решение в файл-владелец. Если появилась новая отложенная тема, добавь строку в реестр.
5. Запусти `python3 tools/docs-lint.py` и исправь все замечания.
6. Сообщи пользователю: что обновлено, что осталось не определено.

## Границы

- Не делай коммит.
- Не правь конституцию сам: поправки идут через `/speckit-constitution` с подтверждением пользователя.
- Не придумывай содержимое для отложенных тем.
