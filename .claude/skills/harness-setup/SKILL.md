# harness-setup

> **Отвечает за:** порядок установки окружения харнеса в свежем клоне на macOS, Linux и Windows: какие зависимости нужны, в каком порядке их ставить, что делает агент сам, а что запускает владелец.
> **Не содержит:** назначения зависимостей ([infrastructure.md](../../../docs/harness/infrastructure.md#внешние-зависимости)), устройства хуков и проверок ([reference.md](../../../docs/harness/reference.md#автоматизация-ai-среды)), окружения сервиса ([development](../../../docs/development/README.md)).
> **Читать когда:** пользователь вызвал `/harness-setup`, только что клонировал репозиторий или проверка окружения сообщает, что чего-то не хватает.
> **Проверено при версии конституции:** 3.0.0

**TL;DR:** агент запускает `python3 tools/harness-setup.py check`, выполняет напечатанные команды установки, включает git-хук, прогоняет проверку документации и тесты харнеса и просит перезапустить Claude Code. Единственное, что должно быть до запуска, это Claude Code. Проверено на macOS, на Linux и Windows команды взяты из документации инструментов и в живой работе не прогонялись.

## Зависимости

| Что | Зачем | Обязательна |
|---|---|---|
| Claude Code | запускает агента, скиллы и хуки | да, ставится до вызова скилла |
| git, bash, diff, patch | git-хук, тесты, защита от дрейфа шаблонов Spec Kit. На Windows все четыре дает Git for Windows, без него Claude Code не использует bash и хуки проекта не работают | да |
| Python 3 по имени `python3` | все скрипты и хуки вызывают именно `python3` | да |
| плагин OMC | исполнение задач по ролям, ставится на уровне пользователя | да |
| uv | ставит Spec Kit CLI, а там, где нет Python 3, и его | нет |
| Spec Kit CLI (`specify`) | только цепочка `feature-chain`, версия проекта записана в `.specify/init-options.json` | нет |

## Шаги

1. Запусти `python3 tools/harness-setup.py check`. Скрипт определяет ОС и пакетный менеджер, печатает таблицу зависимостей и команды установки недостающего по порядку.
2. Если команда `python3` не найдена, скрипт запустить нельзя. Поставь Python 3 по таблице ниже и повтори шаг 1.
3. Выполняй напечатанные команды по одной и показывай вывод. Команды с `sudo`, `winget`, `xcode-select --install` и установщики, которые требуют пароль или подтверждение в окне, сам не запускай: покажи команду и попроси владельца выполнить ее в этой сессии через префикс `!`, затем продолжи. Остальные команды выполняй сам.
4. После установки плагина OMC Claude Code нужно перезапустить, плагин появится только в новой сессии. Скажи об этом и продолжай остальные шаги.
5. Включи git-хук: `python3 tools/harness-setup.py hooks`.
6. Повтори `python3 tools/harness-setup.py check`, пока не останется обязательных пунктов со статусом НЕТ. Необязательные пункты без uv и Spec Kit CLI допустимы, скажи владельцу, что без них не запускается цепочка `feature-chain`.
7. Прогони `python3 tools/docs-lint.py` и `python3 -m unittest discover -s tests/harness`. Если что-то упало, покажи вывод и не объявляй установку завершенной.
8. Попроси владельца перезапустить Claude Code, чтобы применились настройки проекта и плагин, и после перезапуска вызвать `/harness-guide`.

## Установка Python 3 без скрипта

| ОС | Команда |
|---|---|
| macOS | `brew install python`, без Homebrew: `curl -LsSf https://astral.sh/uv/install.sh \| sh`, затем `uv python install --default` |
| Linux | пакет `python3` пакетным менеджером дистрибутива, например `sudo apt-get install -y python3` |
| Windows | в PowerShell `winget install --id astral-sh.uv -e`, затем в Git Bash `uv python install --default`, он кладет `python3` в папку bin пользователя |

После установки откройте новый терминал или новую сессию Claude Code, чтобы обновился PATH.

## Границы

- Файлы репозитория не правь, кроме того, что делают сами команды скрипта.
- Не ставь ничего сверх таблицы зависимостей и не меняй глобальные настройки пользователя, кроме установки плагина OMC и Spec Kit CLI.
- Не вводи пароли и не обходи запросы подтверждения установщиков.
- Окружение сервиса (Go, Docker, линтеры) этот скилл не ставит, оно описано в [development](../../../docs/development/README.md#окружение-и-установка-зависимостей).
