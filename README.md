# Movie Service

> **Отвечает за:** вход в проект: назначение, возможности и навигация к стеку, структуре репозитория и запуску.
> **Не содержит:** правил и стека ([конституция](.specify/memory/constitution.md)), инструкций агентам ([AGENTS.md](AGENTS.md)), деталей архитектуры и эксплуатации ([docs/](docs/README.md)).
> **Читать когда:** впервые открываете репозиторий.

**TL;DR:** Movie Service - сервис совместного просмотра фильмов. Он разрабатывается по Spec Kit и с упором на AI-нативную среду. Сейчас в репозитории только AI-среда и документация, кода еще нет.

## Назначение и возможности

Назначение: совместный просмотр фильмов. Возможности и структура MVP не определены, их опишет владелец проекта, после этого раздел будет заполнен. См. [реестр отложенных решений](docs/decisions/README.md#отложенные-решения).
