# Разработка

> **Отвечает за:** руководство разработчика: проверка документации, автоматизация AI-среды, а позже окружение, команды, тестирование.
> **Не содержит:** принципов ([конституция](../../.specify/memory/constitution.md)) и инструкций агентам ([AGENTS.md](../../AGENTS.md)).
> **Читать когда:** настраиваете клон репозитория или ищете, как проверить и запустить.

**TL;DR:** кода еще нет, поэтому сборка, окружение и тесты намеренно не определены, см. [реестр отложенных решений](../decisions/README.md#отложенные-решения). Описаны только проверка документации и автоматизация AI-среды.

## Первичная настройка клона

После клонирования выполните один раз:

```bash
git config core.hooksPath .githooks
```

Затем перезапустите Claude Code, чтобы применились настройки проекта.

## Проверка документации

Запуск, нужен только Python 3 и его стандартная библиотека:

```bash
python3 tools/docs-lint.py
```

Проверяются:

- шапка в каждом файле документации и инструкций, включая скиллы проекта
- относительные ссылки и якоря
- наличие каждого файла в [карте источников истины](../README.md#карта-источников-истины)
- ссылка на реестр отложенных решений там, где есть неопределенные темы
- запрещенные символы типографики
- формат версии и дат конституции
- переопределение шаблона задач, в котором тесты обязательны
- настройки плагинов проекта
- наличие каждого файла харнеса на [схеме связей](../README.md#схема-связей)

Режим `--staged` запускает git-хук. Он дополнительно проверяет по индексу, что версия конституции стала больше прежней и что в ней нет временного отчета о синхронизации. Остальные проверки читают рабочее дерево.

## Автоматизация AI-среды

| Механизм | Где настроен | Что делает |
|---|---|---|
| настройки Claude Code | `.claude/settings.json` | отключает перечисленные в файле плагины, запрещает чтение `.env` инструментом Read, force push и `--no-verify`, требует подтверждения правки конституции. Новый установленный плагин нужно добавить в список |
| хук после правки | `.claude/settings.json`, `tools/docs-lint.py` | проверяет документацию после правки файла |
| хук перед командой | `.claude/settings.json`, `tools/guard-constitution.py` | требует подтверждения, если команда похожа на запись в конституцию. Это эвристика по тексту команды, а не гарантия |
| хуки Spec Kit | `.specify/extensions.yml` | после `/speckit-implement` и `/speckit-constitution` запускают `/docs-sync` |
| скилл `docs-sync` | `.claude/skills/docs-sync/SKILL.md` | сверяет изменившиеся факты с файлами-владельцами и запускает проверку |
| git-хук | `.githooks/pre-commit` | запускает проверку перед коммитом |
| шаблон задач | `.specify/templates/overrides/tasks-template.md` | делает тесты обязательными и ставит их первыми, как требует принцип VI |
| напоминания о записи знаний | `.claude/settings.json`, `tools/capture-reminder.py` | хук Stop раз в 12 ходов просит агента проверить незаписанные решения. Хуки PreCompact и SessionEnd ничего не передают модели и только помечают сессию, хук SessionStart напоминает о пометке в следующей сессии |
| скилл `capture` | `.claude/skills/capture/SKILL.md` | записывает решение из чата владельцу после подтверждения |
| скилл `harvest` | `.claude/skills/harvest/SKILL.md`, `tools/harvest.py` | ищет повторяющийся контекст в расшифровках сессий и в памяти Claude |
| скилл `cold-start` | `.claude/skills/cold-start/SKILL.md` | проверка с чистого листа по контрольным вопросам и замер размера контекста |

Заметки к таблице:

- Формат расшифровок сессий внутренний и может измениться. Если `tools/harvest.py` перестал находить реплики, он предупреждает об этом.
- Состояние напоминаний лежит вне репозитория: `~/.claude/projects/<проект>/capture/`. Частота напоминания хука Stop задается переменной окружения `CAPTURE_REMIND_EVERY`.
- Снять напоминание о неразобранных сессиях можно командой `python3 tools/capture-reminder.py clear`.
