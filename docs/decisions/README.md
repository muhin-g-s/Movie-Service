## Формат ADR

ADR лежит в этой папке в файле `NNNN-имя.md`, номер из четырех цифр идет подряд. Файл начинается с шапки документа, затем идет строка статуса: предложено, принято или заменено ADR с указанным номером. Разделы: Контекст, Решение, Рассмотренные варианты, Последствия, Связанные файлы.

ADR фиксирует причины и альтернативы. Текущие правила остаются в файлах-владельцах, а ADR ссылается на них. Новый ADR добавляется в указатель выше, проверка документации этого требует. Решение, которое меняет принципы, сопровождается поправкой конституции, ее обоснование ссылается на ADR. Архитектурное решение из плана фичи при необходимости оформляется как ADR, чтобы пережить фичу.
