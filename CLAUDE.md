## Claude Code

- Скиллы Spec Kit лежат в `.claude/skills/speckit-*` и устанавливаются интеграцией Spec Kit. Здесь их не перечисляем.
- Настройки Claude Code (settings, hooks, permissions) не определены. Решим, когда понадобятся, см. [реестр отложенных решений](docs/decisions/README.md#отложенные-решения).

## OMC

OMC - плагин оркестрации исполнения, подключен на уровне пользователя, а не проекта. Он подчиняется разделу "Разграничение процесса" в [AGENTS.md](AGENTS.md#разграничение-процесса). Правила применения:

- `.omc/` игнорируется git и не является источником истины.
- Автономные режимы (`autopilot`, `ralph`, `ultrawork`, `team`) только на утвержденные задачи из `tasks.md`. На идею не запускать: `autopilot` идет от идеи к коду и обходит спецификацию (принцип I).
- Режимы планирования OMC (`plan`, `ralplan`) для работы по фиче не использовать: планирование ведет Spec Kit.
- Стартовая раскладка ролей по шагам выполнения задачи, уточняется по опыту первой фичи:

| Шаг | Роль OMC |
|---|---|
| исследование | `document-specialist`, `explore` |
| тесты | `test-engineer` |
| реализация | `executor` |
| проверка | `verifier`, `code-reviewer` по [code-review.md](code-review.md) |
