## Claude Code

- Настройки проекта лежат в `.claude/settings.json`: плагины, разрешения и хуки. Механика описана в [справочнике харнеса](docs/harness/reference.md#автоматизация-ai-среды).
- Скиллы Spec Kit лежат в `.claude/skills/speckit-*` и устанавливаются интеграцией Spec Kit. Здесь их не перечисляем.
- Скиллы проекта, например `docs-sync`, лежат в `.claude/skills/` под именами без префикса `speckit-`. Оформлять новые помогает `skillify` из OMC, файл скилла оформляется как остальные документы харнеса.

## OMC

OMC - плагин оркестрации исполнения, подключен на уровне пользователя, а не проекта. Он подчиняется разделу "Разграничение процесса" в [AGENTS.md](AGENTS.md#разграничение-процесса). Правила применения:

- Режимы `autopilot`, `ralph`, `ultrawork` и `team` подпадают под правило об автономных режимах из [AGENTS.md](AGENTS.md#разграничение-процесса). `autopilot` идет от идеи к коду и обходит спецификацию, поэтому на идею его не запускать.
- Режимы планирования OMC (`plan`, `ralplan`) для работы по фиче не использовать: планирование ведет Spec Kit.
- Стартовая раскладка ролей по шагам выполнения задачи, уточняется по опыту пилотной фичи:

| Шаг | Роль OMC |
|---|---|
| исследование | `document-specialist`, `explore` |
| тесты | `test-engineer` |
| реализация | `executor` |
| проверка | `verifier`, `code-reviewer` по [code-review.md](code-review.md) |
